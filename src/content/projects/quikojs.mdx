## About *QuickJs*

QuickJs: The Next.js Headless CMS for Non-Technical Users, code-first headless CMS and application framework native to Next.js. It installs directly into your existing project—eliminating the need for third-party SaaS subscriptions. Developers use it to manage databases, automatically generate a React-based admin UI, and build full-stack applications.

## Key Features

Describe the scope of the library. **Power anything you can imagine.**

- Headless CMS
- Digital Asset Management
- Custom Themes
- One-Click Installation
- Auto Layout (Desktop, Mobile, Tab)
- 30+ Components

**Code-First Configuration:** Manage your database schemas, user roles, authentication, and localization entirely in TypeScript/JavaScript via a strongly typed config.

**Next.js Native:** It functions directly within the Next.js App Router, supporting modern features like React Server Components, Live Preview, and on-demand revalidation.

**Self-Hosted Flexibility:** Run it anywhere, including cost-effective serverless platforms like Vercel, Render, or Netlify.
